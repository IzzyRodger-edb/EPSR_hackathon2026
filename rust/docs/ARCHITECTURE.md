# Architecture of `epsr-core`

This document describes how the Rust engine is organised, what each source
file contains, and how one EPSR iteration flows through the code.  For the
correspondence with individual Fortran routines see
[FORTRAN_MAP.md](FORTRAN_MAP.md).

## Design principles

1. **Literal translation.**  The goal of this first conversion is fidelity,
   not idiomatic Rust.  Variable names are the Fortran names; arrays are
   1-based and column-major (`F1`, `F2`, `F3` in `fortran/array.rs`); loops,
   branches and the order of every floating-point operation follow the
   original.  This is what makes byte-identical output possible, and it lets
   any line of Rust be checked against the corresponding Fortran.
2. **Single-precision arithmetic as in the Fortran.**  `real` → `f32`,
   `real*8` → `f64`, with mixed-precision expressions promoted exactly as
   gfortran does (e.g. `sum = sum + cwt*soq` with `real*8 cwt` is written
   `sum = (sum as f64 + cwt * soq as f64) as f32`).
3. **One state object.**  All Fortran COMMON blocks and module variables live
   in `state::State`; routines are methods on it.  The driver `epsr::Epsr`
   owns a `State` plus the run-level variables that were locals of
   `runepsr17`.
4. **Fail loudly on unported features.**  Code paths the test case does not
   need and that cannot be reproduced (the Fortran crashes, hangs or reads
   uninitialised memory) return `EpsrError::Unsupported("...")` instead of
   silently doing something different.

The CLI (`epsr-cli/src/main.rs`) parses `<folder> epsr <file>` and calls
`Epsr::setup` + `Epsr::run`.

## The state model (`state.rs`)

| struct | Fortran | key contents |
|--------|---------|--------------|
| `Lattice` | `lattice.inc` | box vectors (`alatx`, `blaty`, `clatz`, …), `cubic` |
| `Mol` | `molecom.inc`, `clustercom.inc`, `molecom_mod` | atoms (`xa/ya/za` relative to molecule centre, `alabel`, `itype`, bonds `iabond/tbond`), molecules (`xadd/yadd/zadd` centres, `naf..nal` atom ranges, `mtype`), atom types (`type_`, `epscor`, `sigcor`, `charge`, `amassa`), pair tables (`npairref`, `n1extr`, `n2extr`), MC step sizes per molecule type (`interntrans`, `internrot`, `wholerot`, `wholetrans`) and acceptance counters |
| `Dist` | `epsr16.inc` | r grid `x`/`xstar`, uniform-density shell counts `ycoh`, Fourier kernel `foqols(r,Q)`, running-average partials `gorinter/gorintra(r,pair)`, `soqinter/soqintra(Q,pair)`, data ranges `nqmin/nqmax` |
| `Pot` | `potential_par.inc` | EP coefficients `pcoefp(coef,pair)`, per-dataset fits `pcoefd`, tabulated potentials and gradients: reference `ecoul/ecoul1`, `epot/epot1`, empirical `xavs/xavs1`, intramolecular `xav/xav1`, total `xavtot`; basis tables `expgr`, `expsq`; `potfac`, `feedback`, `absolute_energy` (ereq) |
| `Weights` | `weights.inc` | `cwt/ciwt(dataset,pair)` (inter/intra weights), inverse weights `cwttq`, `cwtpot` |
| `InputPar` | `epsrinput_par.inc` | counters `nisum`, `nsum`, running energy/pressure averages, EP parameters (`rminpt`, `rmaxpt`, `expecf`, …) |
| `Symbols` | `symbols.inc`, `iresetnumbers.inc`, `directory_name.inc` | keyword table, file names, directory |
| `CellList` | module `cellneighbourlist` | cell decomposition |
| `ErgPairs` | module `ergpairreference` | stored molecule–molecule energies and the per-molecule neighbour list |
| `Timer` | module `timer` | wall-clock counters (only written to `fort.35`) |

**Units.**  Between `normalise_coordinates` and `unnormalise_coordinates` all
lengths are in box-fraction units: molecule centres divided by `dmax` (box
side), atom offsets by `dmaxmol = dmax*sizefactor`.  The r grid `x` is in Å,
`xstar = x/dmax`.  Energies are kJ/mol; `simt = 0.008314*T` is kT.

## Data flow

### `Epsr::setup` (Fortran `runepsr17` up to the iteration loop)

1. `setup_symbols_epsr` — install keywords and defaults.
2. `setup_input_file` + `read_input_file` — read `.EPSR.inp`; the
   `fnameato` and `fnamepcof` lines trigger `read_ato` → `minitc` (reads the
   configuration, builds atom types, pair tables, densities, dipoles, restores
   the RNG state) and `read_pcof` (EP coefficients, pair matching).
3. Parse run parameters from the keyword table (positionally, as the Fortran does).
4. `inita` — EP parameters, r grid, `ycoh` (`uniform`), Q grid, Fourier kernel
   `foqols` (from `j1qr`), and the accumulators in `.EPSR.inpa`.
5. `get_wts` — neutron weights → `cwt`, `ciwt`, `cwtpot`.
6. `normalise_coordinates`, `get_maxmolsize`, `initg` (read accumulated
   g(r)/S(Q) from `.g01 .y01 .f01 .s01`), `initpt` (truncation windows,
   `generate_rp` reference potential, `generate_ep` empirical potential).
7. Read each data file, interpolate onto the Q grid (`interp`).
8. `lsparabola1` — read the `.erg` history, write `.qdr`.

### `Epsr::iterate` (one pass of `do 3000 iter=1,niter`)

1. `initialise_cellneighbourlist`, wrap molecules into the box,
   `fmolec1` (all energies, stored pair energies).
2. `ntimes` × `molfit` (Monte Carlo cycle).  After a molecule shake
   (`nisum == 1`) `adjust_intra_wts` and `fmolec1` are re-run.
3. `atogen` (histograms of the current configuration) → `gensq` (partial
   S(Q)) → `entrpc`; `sumsq`, `sumgr` (running averages), `entrpb`; `press`
   (energy, pressure); running averages of energy and pressure.
4. Data minus simulated intramolecular part; background removal with
   `ftback`.
5. `ptgnsq` — fit data − simulation per dataset with Q-space basis functions
   (`calc_pwrexpq`, `fit_expansion`), add to the pair coefficients via
   `cwtpot`, rebuild the EP (`generate_ep`); writes `delfit.dat`.
   `repulsivept` updates repulsive cores and the reference potential.
6. On the last iteration `write_results`: `.terg` (`sumpe`), estimated
   partials from the data, all `.?01` files (`w_int`/`w_intr`), R-factors,
   r-space quality coefficient; `norma` (`.inpa`, `.uni`).
7. Append to `.erg`, write `.out`, update keyword values, unnormalise,
   save `.EPSR.inp`, `.pcof`, `.ato` (`moloutc`), renormalise.

`Epsr::run` = `iterate(1..=niter)` + `write_fort35`.

## Functions by file

### `symbols.rs`
* `setup_symbols_epsr` — keyword table and defaults (from `symtab.rs`).
* `setup_input_file(name)` — derive `fname_inp`, `fname_run`, open the input file.
* `read_input_file(file)` — process every line; returns the Fortran `ierrout`.
* `apply_input_lines(lines)` — process extra lines as if appended to the file (parameter overrides).
* `process_commands` (private) — one line: `keyword value`, `data n`, `q`, ….
* `check_symbol` (private) — validate a value; resequence per-dataset values when `ndata` changes; trigger `read_ato` / `read_pcof`.
* `save_inp_file`, `save_pcof_file` — rewrite `.EPSR.inp` / `.pcof` from the table.

### `ato.rs`
* `read_ato(icount, ifilecount)` — resolve the `.ato` name and call `minitc`.
* `minitc(path)` — parse a `.ato` file (layout documented in the module header).
* `ftype(ia)`, `ctype(...)` — atom type assignment and type parameters.
* `bondnumbers` — convert per-molecule atom numbers to global numbers.
* `normalise_coordinates`, `unnormalise_coordinates` — Å ↔ box units.
* `get_maxmolsize`, `centreofmassi(im)`.
* `moloutc(path)` — write a `.ato` file.
* helpers `cosd`, `sind`, `scapro`, `vecpro`, `perpd`, `get_atomicnumber`.

### `pcof.rs`
* `read_pcof(icount, ifilecount)` — header keywords, pair potentials, pair matching.
* `write_pcof_pairs(out)` — pair section of the `.pcof` file.

### `neighbour.rs`
* `minimage`, `minimagec` — minimum image (cubic box).
* `State::initialise_cellneighbourlist(nmolcell, rmax)`, `makecellneighbourlist` — cells and neighbouring-cell offsets.
* `CellList::make_neighbour_list_from_cells(ic, nbref)`, `get_nnbrefmax`.
* `State::initialise_ergpair`; `ErgPairs::set_ergpair`, `get_neighbsum`, `make_neighbour_list_from_mols`, `save_energies`, `save_erg_pairs`.

### `energy.rs`
* `en_atom_inter_scale` — atom–atom intermolecular energy (EP + reference, interpolated).
* `en_mole_pair(im, jm)`, `en_atom_intra`, `en_mole_intra(im)`, `en_mole_dihedral` (0 for ROT groups).
* `en_change(im)`, `en_change_intra(im)` — energy changes for a trial move.
* `fmolec1` — all energies + stored pairs; returns energies per molecule.
* `adjust_intra_wts`, `abs_energy_ep`, `press` — energy and pressure.

### `montecarlo.rs`
* `molfit(fadds, faddbs, intra, rotfreq, ireset)` — one MC cycle + step-size adaptation.
* `movea`, `movei`, `movem`, `rotati`, `rotatm` — moves; `internal_rotation_move` — rotational-group move with Metropolis test.

### `structure.rs`
* `inita(...)` — grids, Fourier kernel, `.inpa` accumulators; returns `(q, z, nz)`.
* `uniform`, `interp`, `lorch`, `stog` (S(Q) → g(r)).
* `atogen(wav, ngrsamples)`, `gensq(nq, sofq, wav)`, `entrpc`, `entrpb`, `sumsq`, `sumgr`, `ftback`.

### `potential.rs`
* `truncate`, `truncatec`, `chsph`, `dnext`, `expand`, `smoop`, `fctrln`.
* `calc_pwrexpr_grad`, `calc_pwrexpq` — EP basis functions in r and Q.
* `State::fit_expansion` — MC fit of basis coefficients.
* `initpt`, `generate_mp`, `generate_rp`, `generate_ep`, `multiply_pot_coeffs`, `repulsivept`, `ptgnsq`.
* `lsparabola1` (free function) — `.erg` trend fit, writes `.qdr`.

### `weights.rs`
* `get_wts(files, ireset, q, nq)` — read `.wts` (neutron) or X-ray weights, form `cwt`, `ciwt`, `cwtpot`; `wtype`.
* `read_xray_weights`, `wxtype`, `wxcreate` (writes `X-raywts.dat`, `X-rayf0x.dat`), `recompute_cwttq`, `invert_cwt` (MC inversion of the weights matrix).

### `datafile.rs`
* `read_data_points` — the data-reading loop for every `nrtype` (header handling, `backspace`, GENIE `(i7,3g14.7)` fixed format).

### `containerforces.rs`
* `ContainerForces` (module data); `get_containerforce_list` (from `generate_rp`), `en_containerforce` (in `fmolec1`/`en_change`), `dist_containerforce` (in `atogen`).

### `threebody.rs`
* `ThreeBody` (module data); `read_pcof_threebody`/`write_pcof_threebody` (`tb` lines), `find_triplets`, `get_triplet_pot_cons`, `en_mole_triplets`, `pr_mole_triplets` (virial), `save_threeb_energies`, `en_change_triplets`.

### `coordconstraint.rs`
* `CoordConstraints` (module data); `init_constraint`, `read_coordcon_line`/`write_pcof_coordcons`, `find_constraints`/`find_all_constraints`, `setup_coord_constraints` (from `fmolec1`), `en_mole_coord`, `en_coordcon`, `en_gauss`, `en_harmonic`, `check_coord_bonded`, `save_coord_energies`, `writecoordcons` (`coordcon.txt`), `scale_coordconstraint_lengths`.

### `coarsegrain.rs`
* `CoarseGrain` (module data); `inita_coarsegrain` (the coarse-graining block of `inita`, writes `formfactors.txt`, `intraformfactors.txt`, `intraformfactorsself.txt`), `gaussianqr2`, `atogen_cg_alloc`/`atogen_accumulate`/`atogen_normalise` (`wavinter`).

### `pressure.rs`
* `PressureControl::parse` (`control-p`), `control_pressure` (end-of-iteration box or repulsive-core adjustment), `change_boxsize`, `multiply_pcoefex`.

### `bragg.rs`
* `Bragg::read_keywords` (`qwidthqmax`, `hklqmin`, `mplicities`, `diffuse`, `nlatrefine`, `latrefine`), `bragginten` (`.bragg`, `.inten`), `sharm_diffuse` (`.DIFFUSE.h01`), `change_boxsize`, `convertphibthetacphic`, `Epsr::structure_and_lattice` (atogen + gensq inside the lattice-refinement loop).

### `output.rs`
* `w_int`, `w_intr`, `r_int` — the column-file format (table of extensions in the module docs).
* `State::initg`, `sumpe` (`.terg`), `norma` (`.inpa`, `.uni`, keyword updates).

### `epsr.rs`
* `Epsr::setup`, `Epsr::setup_with_lines`, `Epsr::iterate`, `Epsr::run`, `Epsr::write_fort35`.
* private: `write_results`, `write_out_file`, `update_symbols`, `wrap_molecules`.
* structs `Dataset`, `Control`, `Summary`.

### `api.rs`
Accessors returning 0-based slices of the used length: `q_grid`, `r_grid`,
`gr_inter/gr_intra(ip)`, `sq_inter/sq_intra(ip)`, `data_fq(id)`,
`simulated_fq(id)`, `data_q_range(id)`, `empirical_potential(ip)`,
`reference_potential(ip)`, `ep_coefficients(ip)`, `pair_labels`,
`atom_types`, `atom_labels`, `molecule_atoms`, `atom_positions` (Å),
`box_size`, `get_parameter(name, dataset)`, counts.

### `fortran/*`
* `array.rs` — `F1`, `F2`, `F3`; index with `i32` or `usize`; `col(j)` gives a column slice.
* `format.rs` — `fmt(format, &[FV])` interprets FORMAT strings (repeat counts, groups, reversion, `I`, `F`, `E`, `A`, `L`, `X`, `/`, `nH`, quotes) exactly as gfortran; `ListWriter` reproduces list-directed `write(u,*)`; `edit_e`, `edit_f`, `edit_i`, `list_real4`, `list_real8`.
* `listread.rs` — `TextFile` (lines + record pointer + `backspace`), `ListRead` (list-directed READ across lines, null values, `/`, repeat counts), `parse_real`/`parse_int` with Fortran syntax.
* `text.rs` — `parse` (EPSR's word splitter that stops after `nspcword` blanks — how descriptions in input files are skipped), `concatenate`, `indexlastdot`, `substr`, `fstr`.
* `fmath.rs` — integer powers as gfortran compiles them, `nint`, `sign`.
* `output.rs` — `OutFile`.
