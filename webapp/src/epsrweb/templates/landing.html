Refine a structure against your diffraction data

Upload the Gudrun .mint01 files for one material. The agent proposes a model system, runs the Rust EPSR engine and gives you the fit, the partial pair distribution functions, the refined empirical potential and a PDF report.

You can also send any figure straight into the figures/ folder of your Overleaf project.

Before you start

You will need:

  • two to four isotopic samples of the same material, as reduced Gudrun .mint01 tables
  • the composition, temperature and density, if the file headers do not say them
  • an Overleaf project with Git integration, if you want figures pushed for you

Read the instructions for what each file must contain.

How it works

1. Upload

The files are checked before anything is queued: three numeric columns, ascending Q, within EPSR's limits.

2. Refine

A scratch start, an equilibration on the reference potential, then refinement with the empirical potential. You watch every iteration as it happens.

3. Publish

Tick the figures you want. They go to Overleaf over its Git bridge as PDF, each with a ready-made \includegraphics block, or download them as a zip.
