What happens next
  1. The files are validated and copied into a folder that belongs to this run alone.
  2. The agent proposes a model system; the code generates the EPSR inputs and a standalone Python script.
  3. The engine runs a scratch start, an equilibration on the reference potential, then refinement with the empirical potential.
  4. Figures, the tidy CSV tables, the analysis and the PDF report are written; the results page draws its own seaborn figures from the tables.
