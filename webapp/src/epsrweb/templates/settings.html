Overleaf

Overleaf has no public upload API. The supported route is its Git bridge, which this server drives for you: it clones your project, copies the figures you ticked into figures/, commits and pushes.

Git integration is an Overleaf premium feature (Commons institutions, group subscriptions or an individual subscription). Without it the push will be refused and you should use Download zip on the results page instead, which gives you the same figures plus a figures.tex of ready-made blocks to drag into the editor.
